# ระบบติดตามงานซ่อมลูกหีบ (Milling Repair Tracker)

เว็บแอปติดตามความคืบหน้างานซ่อมลูกหีบโรงงานน้ำตาล ปีการผลิต 2568/69

**เปิดใช้งาน:** https://boboapp2020-design.github.io/MillingTracking/

## คุณสมบัติ
- แผนผังสถานีหีบอ้อย (ภาพ 3D) — คลิกที่เครื่องจักรเพื่อกรอก/ดูรายละเอียดงาน
- คำนวณน้ำหนักงานอัตโนมัติ: `Weight% = (คน × วัน) ÷ ผลรวมทั้งโปรเจกต์ × 100`
- KPI: ความคืบหน้าจริง vs แผน, S-Curve, จุดที่ต้องเร่ง
- ปฏิทินวันทำงาน/วันหยุด: ทำงานทุกวัน วันละ 8 ชม. หยุดเฉพาะวันอาทิตย์ + วันหยุดพิเศษ 11/09/2026 และ 26/10/2026 (`HOLIDAYS` ใน shared.js) · น้ำหนักงาน = คน × วัน × 8
- เก็บข้อมูลในเบราว์เซอร์ (localStorage) + ซิงค์ Google Sheet ผ่าน Apps Script
- ทำงานออฟไลน์ได้ (ไฟล์ HTML เดียว ฝังภาพ/สคริปต์ในตัว ไม่พึ่ง CDN)

## การเชื่อม Google Sheet
1. เปิด Google Sheet → ส่วนขยาย → Apps Script → วางโค้ดจาก `Code.gs` → บันทึก
2. Deploy → New deployment → Web app (Execute as: Me, Access: Anyone) → คัดลอก URL (/exec)
3. ในเว็บ กดปุ่ม "☁️ เชื่อม Sheet" → วาง URL

ดูรายละเอียดขั้นตอนในหัวไฟล์ `Code.gs`
